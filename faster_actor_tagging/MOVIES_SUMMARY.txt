================================================================================
                        WHAT YOU NEED TO DO NEXT
================================================================================

FOR EACH MOVIE YOU WANT TO PROCESS:

1. Open the config file
   └─ Example: nano config_rockstar.py

2. Update MOVIE_FRAMES_DIR to your movie frames path
   └─ Change: MOVIE_FRAMES_DIR = '/path/to/your/movie/frames'
   └─ To:     MOVIE_FRAMES_DIR = '/actual/path/to/rockstar/frames'

3. Run the pipeline
   └─ python run_movie.py rockstar

4. Check output directory
   └─ ls -la rockstar_output/

================================================================================
                            PIPELINE STAGES
================================================================================

The main.py pipeline runs 4 stages:

STAGE 1: Face Detection (GPU)
  └─ Detects all faces in movie frames
  └─ Output: faces_detected.csv

STAGE 2: Embedding Generation (CPU)
  └─ Generates facial embeddings for detected faces
  └─ Output: embeddings/*.pkl

STAGE 3: Actor Search (FAISS)
  └─ Matches actor embeddings against frame embeddings
  └─ Output: faiss/results/*.csv

STAGE 4: Image Generation
  └─ Draws bounding boxes on frames
  └─ Output: annotated_images/*

Each stage can be skipped by setting SKIP_* flags in config if already done.
